# 📝 User Registration Form

A responsive and interactive **User Registration System** built using **HTML, CSS, JavaScript, jQuery** with dynamic table operations and client-side validation.

---

# 🚀 Features

* ✅ User Registration Form
* ✅ Client-Side Validation using jQuery
* ✅ Dynamic Data Binding to Table
* ✅ Delete Row Functionality
* ✅ Responsive UI Design
* ✅ Modern Gradient Interface
* ✅ Status Management (Active / Not Active)

---

# 📋 Form Fields

The application contains the following input fields:

* 👤 Name
* ⚧ Gender
* 📱 Mobile Number
* 🎓 Qualification
* 🏠 Address
* ✅ Active Status Checkbox

---

# ⚡ Validation Rules

The form validates user input before saving data:

| Field         | Validation                      |
| ------------- | ------------------------------- |
| Name          | Cannot be empty                 |
| Gender        | Must be selected                |
| Mobile Number | Must be a valid 10-digit number |
| Qualification | Cannot be empty                 |
| Address       | Cannot be empty                 |

---

# 💾 Save Functionality

* On clicking the **Save Record** button:

  * All fields are validated using **jQuery**
  * User data is captured dynamically
  * Data is appended to the table without page refresh
  * Form resets automatically after successful save

---

# 🗑️ Delete Functionality

* Each table row contains a **Delete** button
* Clicking the button removes the corresponding row dynamically using jQuery
